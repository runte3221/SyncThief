# SyncThief 開発完了報告 (Walkthrough)

Player Sync (MareSempiterne) で同期された他プレイヤーの MOD ファイルを Penumbra 経由で逆引きし、部位・スロットごとに選択して即座に使える `.pmp`（Penumbra Mod Pack）ファイルとして出力する Dalamud プラグイン **SyncThief** の開発・ビルド・リリースが完了しました。

---

## 主な実装内容

### 1. リソース逆引き & スロット自動分類 (`Ipc/PenumbraIpc.cs`, `Services/ResourceScanner.cs`)
- Penumbra の公式 IPC (`GetGameObjectResourceTrees`) を呼び出し、対象キャラクターが現在解決している全アセットの依存ツリー（モデル、マテリアル、テクスチャ、およびキャッシュ実体パス `F:\Player Sync Storage\...`）を取得。
- ゲームパス（`chara/equipment/e...`, `chara/human/c.../obj/hair/...` 等）とノード属性から、以下の部位に自動分類：
  - **頭防具 (Head)**
  - **胴防具 (Body/Top)**
  - **手防具 (Hands)**
  - **脚防具 (Legs)**
  - **足防具 (Feet)**
  - **耳・首・腕・指アクセサリ**
  - **髪型 (Hair)**
  - **顔 / メイク (Face)**
  - **体型 / 肌 (Body/Skin)**
  - **武器 (Weapon)**
- ゲーム標準のファイル（`.dat`）を除外し、他プレイヤーから同期されたキャッシュ実体ファイルのみを正確に抽出。

### 2. 即時利用可能な `.pmp` パッケージャー (`Services/PmpPacker.cs`)
- 選択された部位のリソースから、Penumbra 標準の Mod Pack 構造を自動生成：
  - `meta.json`: Mod名、バージョン、作者情報
  - `default_mod.json`: ゲーム内仮想パスとファイル実体のマッピング定義
  - ZIP 内部にゲーム内パス構造でキャッシュ実体ファイルを格納
- 非同期（Task）バックグラウンド処理により、大容量ファイルのエクスポート時もゲームや UI がフリーズしません。

### 3. 操作画面 UI (`UI/MainWindow.cs`)
- コマンド `/syncthief` または Dalamud プラグイン設定から開くメインウィンドウ。
- **プレイヤー選択**:
  - 現在ターゲットしている他プレイヤーを最優先で自動フォーカス。
  - 周囲の他プレイヤー一覧のドロップダウン切り替え。
  - プレイヤー名、ワールド、同期 MOD ファイル数、合計容量のリアルタイム表示。
- **部位選択**:
  - 部位ごとのチェックボックス（ファイル数、容量付き）。
  - 「すべて選択」「すべて解除」の 1 クリックボタン。
  - アコーディオンを展開して含まれるファイル名と実体パスを個別確認可能。
- **出力設定 & 実行**:
  - Mod 名入力（初期値: `SyncThief_{PlayerName}`）。
  - 出力先フォルダ指定（「参照...」ボタンでフォルダ選択ダイアログ表示、初期値: デスクトップ）。
  - 「選択した部位を .pmp に出力」ボタン。
  - 出力進捗プログレスバー、完了通知、および `[ 保存先フォルダを開く ]` ボタン。

### 4. 配布・リリース自動化
- GitHub リポジトリ: `https://github.com/runte3221/SyncThief.git`
- GitHub Actions により Windows / .NET 10 環境で自動ビルドされ、Release `latest` に `latest.zip` が公開されました。
- 既存のランチャー登録 URL（HousingToStagehand- 側の `repo.json`）にも `SyncThief` を追加したため、ランチャー側の URL 変更不要でそのままプラグイン一覧に表示されます。
- GitHub の説明欄・README はご指示通り空構成としています。

## インストールおよび利用手順

1. **ゲーム内ランチャーでインストール**:
   - ランチャーの Dalamud 設定を開き、「プラグイン」一覧を更新します。
   - プラグイン一覧に **`SyncThief`** が表示されますので、「インストール」をクリックします。
   （※もし一覧に出てこない場合は、プラグイン設定の「テスト版」またはリポジトリの再読み込みを行ってください）
2. **SyncThief を開く**:
   - チャット欄に `/syncthief` と入力して Enter を押すか、プラグイン一覧の「開く」を押します。
3. **対象プレイヤーと部位の選択**:
   - MOD を取得したい他プレイヤーをターゲット（または画面上のドロップダウンから選択）します。
   - 取得したい部位（胴防具のみ、髪型のみ、すべてなど）のチェックボックスを選択します。
4. **エクスポート**:
   - 「選択した部位を .pmp に出力」ボタンをクリックします。
   - デスクトップ（または指定フォルダ）に `.pmp` ファイルが生成されます。
5. **Penumbra へのインポート**:
   - Penumbra の画面を開き、左下の「Modのインポート」から生成された `.pmp` を選択するだけで、即座に通常の MOD として使用・装備できます。
